# Scripts (virtual signals)

SVMonitor can run user scripts (Lua) to build **virtual signals** from existing ones.

![Scripts](../images/scripts.png)

The booklet shows examples: scale a signal, gate values, combine signals. Monitor opens the dialog in player mode on the live stream (`SV_Script::ModeGr::Player`).

This page does not document the full Lua API; use the examples inside the dialog.
