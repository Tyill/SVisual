# Назначение

SVisual — мониторинг работы МК: живые графики, архив на диске, оповещение при срабатывании условия.

**SVMonitor** умеет:

- Подключаться по COM/UART (USB у Arduino) или TCP (Ethernet / Wi-Fi)
- Опрашивать сигналы в реальном времени (по умолчанию **10 Гц**; период от 1 мс, пакет до 1e6)
- Писать до **2048** сигналов на все модули
- Выводить выбранные сигналы на график и значения маркеров в таблицу
- Писать архив на диск и при необходимости в **ClickHouse**
- Открывать архив в **SVViewer**
- Запускать пользовательский процесс при **триггере**
- Появлять сигнал только с клиента — на ПК достаточно настроек связи
- Экспортировать в **json / csv / xlsx**
- Отдавать просмотр в **браузере** и работать как пассивный агент **Zabbix**

Клиенты **пушат** значения. API «подписаться / прочитать с сервера» нет.

## Системные требования (из буклета)

- ОС: Windows 64-bit (7, 8, 10) или Linux
- Процессор: не ниже Pentium 4 (буклет)
- ОЗУ: не ниже 512 МБ (буклет)

Зависимости для сборки на Linux — в [compile.md](compile.md).
