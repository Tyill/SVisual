# Интерфейс

Главное окно **SVMonitor**:

![Главное окно](../images/ui-main.png)

| Область | Назначение |
| --- | --- |
| **Список сигналов** (слева) | Модули и сигналы. Двойной щелчок или перетаскивание на график. |
| **Панель состояния** | Подключение, новые сигналы, срабатывания триггеров. |
| **Рабочая область** | Живые графики. |
| **Таблица значений** | Значения в маркерах. |
| **Панель инструментов** | Масштаб, цвета, режим слежения, дополнительные окна. |

## Список сигналов

![Список](../images/signal-list.png)

Индикатор у модуля показывает, идут ли данные.

Ненужный сигнал/модуль: ПКМ → **Удалить**. Активный модуль сначала отключают.

![Удаление модуля](../images/module-delete.png)

Поля **комментарий** и **группа** используются при просмотре архива в SVViewer.

## Панель состояния

![Состояние](../images/status-bar.png)

Типичные сообщения: изменение списка модулей, срабатывание триггера, физическое подключение/отключение.
