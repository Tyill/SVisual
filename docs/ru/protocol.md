# Протокол обмена

Кадр, который шлют `SVClient`, Arduino и принимает `SVServer` (`=begin=` / размер / `=end=`):

![Пакет](../images/protocol.png)

Состав:

1. Маркер `=begin=` (7 байт)
2. `int32` размер полезной нагрузки (little-endian)
3. Имя модуля, `SV_NAMESZ` = **24** байта, дополняется нулями
4. Для каждого сигнала:
   - имя, 24 байта
   - `int32` тип: `0` bool, `1` int, `2` float
   - `packetSz` значений (каждое как `int32`; bool/int — целое, float — биты float)
5. Маркер `=end=` (5 байт)

Размер нагрузки: `24 + N × (24 + 4 + 4×packetSz)` при `packetSz = 10` по умолчанию.

Готовых пакетов C# / Python в этом репозитории **нет**. Приложения Word — примеры этого бинарного кадра, не поддерживаемые SDK.

В именах нельзя использовать строки `=begin=` и `=end=`.
