# Триггеры (пользовательские уведомления)

**Триггер** — условие. При срабатывании SVMonitor может запустить внешний процесс (`userProcPath` + `userProcArgs`).

Диалог открывается с панели (иконка флажка):

![Панель](../images/trigger-toolbar.png)

![Диалог триггеров](../images/trigger-dialog.png)

## Типы событий (`EventType` в `trigger_dialog.h`)

| Тип | Когда |
| --- | --- |
| `CONNECT_MODULE` | Модуль появился |
| `DISCONNECT_MODULE` | Модуль пропал |
| `LESS` / `EQUALS` / `MORE` | Сравнение числа с `condValue` |
| `POS_FRONT` / `NEG_FRONT` | Фронты bool |

Таймаут `condTOut` — в **секундах**.

## Триггеры модуля

Выберите модуль (без сигнала). Условия — подключение / отключение. При необходимости укажите запускаемый процесс.

## Триггеры сигнала

Выберите сигнал. Для **bool** — фронты. Для **int/float** — `<` `==` `>`. Включите **Активно**, затем **Добавить** / **Изменить**.
